# Shared UI primitives

Framework: dependency-free HTML5, vanilla JavaScript, and vanilla CSS. There is no package manifest, meta-framework, component library, or standalone component directory.

There are no separately exported shared primitives. Buttons, inputs, selects, segmented controls, badges, cards, tabs, plots, and console patterns are declarative HTML in ui/static/index.html and shared CSS in ui/static/styles.css. Their complete source is captured without duplication in layouts.md and theme.md.
